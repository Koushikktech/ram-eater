# 🐏 RAM EATER (Re:Zero Ram Memory Devourer) ⚡
### Now featuring REAL official anime pictures & REAL computer RAM photos!

A high-fidelity, interactive web application featuring **Ram** (the pink-haired demon maid from *Re:Zero − Starting Life in Another World* / *Re:Zero kara Hajimeru Isekai Seikatsu*), who literally and physically consumes your computer's RAM, delivers authentic scathing roasts to "Barusu", awakens her demon horn, and plays an arcade memory-catching mini-game!

## ✨ Features

1. **⚡ True Physical RAM Devourer Engine**:
   - Uses real `Uint8Array` / `ArrayBuffer` allocations with a `pageSize = 4096` stride touch to force the OS kernel to commit real dirty physical RAM pages in your Activity Monitor / Task Manager.
   - Emergency **SPIT IT OUT!** button to instantly reclaim 100% of memory.

2. **📊 Real-Time Memory Telemetry & Live Canvas Graph**:
   - Live telemetry for Active Meal, Peak MB, Browser Heap Used/Limit, Demonic Hunger %, and Memory Pressure Bar.
   - Real-time 60 FPS gradient chart tracking memory consumption history.

3. **🔥 Barusu Rig Roasting Chamber**:
   - Inspects system specs (`navigator.deviceMemory`, CPU cores, WebGL GPU, screen resolution).
   - Scathing roasts delivered in Ram's sharp, condescending maid tone.

4. **🔊 Self-Contained Web Audio Synthesizer & Speech**:
   - 100% self-contained Web Audio API synth sounds (crunch, wind whoosh, demon horn surge, spit, roast hit).
   - Web Speech API integration to vocalize Ram's lines.

5. **🎮 Ram's RAM Buffet (Arcade Mini-Game)**:
   - 60 FPS canvas game using real photos of Ram, DDR sticks, and sweet potatoes.
